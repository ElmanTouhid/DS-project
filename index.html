About CorePilot

CorePilot is an interactive CPU Process Scheduling Simulator designed to demonstrate how operating system scheduling algorithms work and how data structures help manage process execution.

Our Project

The platform demonstrates FCFS, Priority Scheduling, and Round Robin using custom implementations of Queue, Min-Heap Priority Queue, and Circular Queue.
